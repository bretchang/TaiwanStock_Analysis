六指標：應收 · 存貨 · 應付 · 營收 · 毛利% · EPS

指標說明 // 財報三表與全部欄位

財報三大表互相連動：綜合損益表看「賺多少」、資產負債表看「家底與體質」、現金流量表看「真的收到多少現金」。獲利好不代表現金流好，三表一起看才能避免被單一數字誤導。

綜合損益表

一段期間（通常一季）公司「收入 − 成本費用 = 賺賠」的成績單。由上而下：營收 → 毛利 → 營業利益 → 稅前/稅後淨利 → EPS。能分辨賺的是本業還是業外。

資產負債表

某一時間點（季底）公司「有什麼（資產）、欠什麼（負債）、自己的（股東權益）」的快照。恆等式：資產 = 負債 + 股東權益。看財務結構是否穩健。

現金流量表

一段期間現金實際的進出，分三類：營業（本業收現，最重要）、投資（買設備/轉投資，擴張期常為負）、籌資（借還款、發股利）。本儀表板已將官方年度累計值還原為單季。

綜合損益表科目
季營收 / 月營收本業賣產品/服務的收入，獲利的源頭。台股每月 10 日前公布上月「月營收」，是最即時的領先指標；季營收則對應財報。
營業成本生產或進貨產品/服務的直接成本。營收 − 營業成本 = 營業毛利。
營業毛利營收扣掉營業成本後的初步獲利，毛利率（毛利÷營收）越高代表產品競爭力與定價力越強。
營業費用推銷、管理、研發等本業營運開銷。毛利 − 營業費用 = 營業利益。
營業利益本業真正的賺錢能力，本儀表板以此與稅後淨利為主軸。排除業外干擾，最能反映本業體質。
營業外收支本業以外的損益（利息、匯兌、處分資產、轉投資等）。波動大且常為一次性，獲利若主要來自業外需提高警覺。
稅前淨利營業利益 + 營業外收支，課所得稅前的總獲利。
稅後淨利扣除所得稅後的最終獲利，是 EPS 與配息的來源。
EPS每股盈餘 = 稅後淨利 ÷ 流通股數，衡量每一股賺多少錢。
資產負債表科目
應收帳款已認列營收但客戶還沒付的錢。應收增速明顯快於營收 → 收款品質惡化或塞貨疑慮。
存貨尚未賣出的原料/在製品/成品。存貨↑但營收↓可能滯銷；存貨↑且營收↑多為備貨迎需求。
合約負債客戶預付但公司尚未交貨/認列的款項（在手訂單）。大增通常是未來營收的領先指標，AI 供應鏈特別值得關注。
應付帳款向供應商進貨但尚未支付的款項，屬無息的營運資金來源；增加有時反映議價力或積極備料。
現金及約當現金最具流動性的資產，反映短期償債與營運調度的靈活度。現金充沛較能抵禦景氣風險。
流動資產 / 流動負債一年內可變現的資產 vs. 一年內須償還的負債。流動資產 ÷ 流動負債 = 流動比率，看短期償債能力。
短期借款一年內到期的銀行借款。金額偏高且現金不足時，需留意周轉與利息壓力。
非流動負債一年以上的長期負債（長期借款、公司債等），通常用於長期投資或擴產。
不動產廠房設備生產用的固定資產，擴張期通常隨資本支出增加。
總資產 / 總負債 / 股東權益公司規模與財務結構。股東權益 = 資產 − 負債，是真正屬於股東的淨值。
現金流量表科目（單季）
營業現金流本業實際收到的現金。若淨利為正但營業現金流長期為負，獲利品質需存疑（可能賺的是帳面數字）。
投資現金流買賣設備、轉投資等的現金進出。擴張期常為負，代表為未來投資。
籌資現金流借還款、發放股利、增減資等的現金進出，反映資金的募集與回饋。
資本支出購置不動產廠房設備的支出，反映擴產與投資力度。
自由現金流營業現金流 − 資本支出，真正可用於配息／還債／再投資的現金。持續為正且穩定是優質公司的特徵。
變動標記與排序

每檔顯示六大指標的 YoY / QoQ 熱力色塊（可於上方「六指標變動」切換）：上升暖色（洋紅）、下降冷色（青綠），色越深變動越大。等級：強烈 ±50%、顯著 30%、留意 15%（毛利% 以百分點 pp 計：±5 / 3 / 1.5pp）。焦點指標可依 YoY / QoQ / 絕對值 / 訊號嚴重度排序。基期過小者自動降權，避免假訊號。

趨勢欄＝你在上方「焦點指標」選的那個指標，最近 8 季（約兩年）的數值走勢迷你圖，末端圓點為最新一期。線形顏色僅比較「最新一期 vs 最早一期」：收高為暖色（洋紅，整體上升）、收低為冷色（青綠，整體下降）。顏色只看頭尾，中間先跌後漲等轉折要看線形本身。數值會正規化到圖框高度，看的是「形狀」而非絕對金額。

訊號說明（交叉判讀）

單看一個指標漲跌容易誤判，「訊號」是結合多個指標的交叉規則，幫你快速判讀。表格最右欄會以彩色標籤呈現：

合約負債暴增合約負債 YoY ≥ 30%。客戶預付／在手訂單大增，通常是未來營收的領先指標，AI 供應鏈題材特別值得留意。
存貨↑營收↓存貨 YoY ≥ 15% 但營收 YoY ≤ 0。貨越積越多、銷售卻沒跟上 → 可能滯銷或需求轉弱（警示）。
備貨迎需求存貨與營收同步成長（皆 YoY ≥ 15%）。增加庫存是為了接單出貨，屬中性偏正。
應收>營收增速應收帳款 YoY 明顯高於營收 YoY（高出 10 個百分點以上）。收款速度跟不上認列營收 → 收款品質惡化或塞貨疑慮（警示）。
獲利背離營收季營收 YoY ≥ 15% 但營業利益 YoY ≤ 0。有量沒利，可能降價搶單或成本上升（警示）。
獲利虛胖稅後淨利 YoY ≥ 15% 但營業現金流 YoY ≤ 0，或營業現金流低於淨利。帳面獲利未轉為現金（警示）。
應付>營收增速應付帳款 YoY 明顯高於營收 YoY（高出 10 個百分點以上）。可能延遲付款或囤料，中性偏留意。
月營收領先走強月營收 YoY 明顯優於季營收 YoY（領先 ≥ 20pp 或方向背離）。需求可能加速，領先季報轉折。
月營收領先轉弱月營收 YoY 明顯落後季營收 YoY（落後 ≥ 20pp 或方向背離）。需求可能放緩，領先季報轉折（警示）。
