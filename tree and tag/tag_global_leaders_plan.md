# 台股 AI 供應鏈：多標籤（Tag）分類系統 + 全球競爭定位研究與規劃

> 用途：把目前 `sub_industry.json` 的「單值次產業」升級成「多值 Tag（一檔多 tag、union-merge）」，並在每個 tag 上疊一層**台 / 美 / 日 / 韓全球龍頭對標**與**競合上下游**註記。
>
> 範圍：聚焦**半導體 + AI 硬體供應鏈**（watchlist 中科技類約 320 檔）。傳產／內需（食品、航運、建材、紡織、鋼鐵、觀光、租賃、製鞋、自行車…）不做全球龍頭對標，僅建議保留 L1/L2 單層產業別。
>
> 時效：競爭格局數字為 **2025–2026 上半年快照**，市占率會變動（尤其 HBM、CPO、液冷併購頻繁），請定期更新。**本文非投資建議。**

## 0. TL;DR — 三個關鍵結論

1. **CCL 那層該拆三段**：成品「高速 CCL/銅箔基板」(台光電、台燿、聯茂) ／ 上游「高階銅箔」(金居) ／ 更上游「玻纖布」(富喬) 是三個不同製程環節、不同競合對象，應拆成三個正交 tag，而非塞在一個 `CCL/PCB材料`。

2. **多 tag 是對的方向**：國巨同時是「電阻全球第一、鉭質電容全球第一、MLCC 全球第三」，單值 sub_industry 永遠表達不了。建議 `tags.json` 用 `stock_id -> [tag,...]`，再獨立一個 `tag_meta.json` 存全球對標知識（分離「歸屬」與「知識」較好維護）。

3. **台股本身就是全球龍頭的 tag 不少**，可以特別標出來（見 §3 表）：
   - 晶圓代工（台積電）、GaAs 代工（穩懋）、ABF 載板（欣興）、OSAT 封測（日月光）、PCB 總產值（臻鼎）、伺服器電源（台達電）、手機鏡頭（大立光）、晶片電阻+鉭電容（國巨）、伺服器管理晶片 BMC（信驊）、NOR Flash（旺宏、華邦電）。

## 1. 標籤系統設計（回答需求 1）

### 1.1 為什麼要從「單值次產業」升級成「多值 Tag」

現行 `sub_industry.json` 是 `stock_id -> 單一字串`，遇到兩種狀況就破功：

| 問題類型 | 例子 | 單值的困境 |
|---|---|---|
| **上下游被混在同一桶** | `CCL/PCB材料` 同時裝了 台光電(成品 CCL)、金居(上游銅箔)、富喬(更上游玻纖布) | 三者是上下游關係，競爭對手完全不同，混在一起無法做供應鏈分析 |
| **一檔跨多產品** | 國巨 = 電阻 + 電容(MLCC) + 鉭電容 + 電感 | 只能歸一類，另外三個面向消失 |
| **題材與產品正交** | 金像電是「PCB 板廠」也是「AI 伺服器」題材 | 產品別與應用題材是兩個維度，不該互斥 |

### 1.2 沿用你現有的三層 + 新增 Tag 層

```
L1  FinMind 官方產業別          （最粗、自動帶入、不動）
L2  sub_industry.json           （單值、主業定位、保留）
L3  tags.json                   （多值、union-merge、正交主題）← 本次重點擴充
```

L2 仍然有用：它回答「這檔**主要**算哪一類」（dashboard 預設分群、排序）。
L3 回答「這檔**沾到哪些**題材／製程環節／產品」（篩選、交叉比較、供應鏈追蹤）。

### 1.3 Tag 設計三原則

1. **正交（orthogonal）**：每個 tag 只描述「一種產品 / 一個製程環節 / 一個應用題材」，彼此盡量不重疊。
2. **三種命名空間**（避免 tag 語意混亂，建議在 `tag_meta.json` 用 `kind` 欄位區分，但 `tags.json` 仍是平面陣列）：
   - `產品`：實際做什麼東西（MLCC電容、ABF載板、光收發模組）
   - `環節`：在供應鏈的位置（上游材料、磊晶、封測、模組組裝）
   - `題材`：終端應用／投資主題（AI伺服器、CoWoS、低軌衛星、矽光子）
3. **多對多**：一檔可掛多個 tag；dashboard 篩選時對 tag 做 **union（聯集）**。

### 1.4 提議的檔案結構（兩個檔，分離「歸屬」與「知識」）

**檔 A：`tags.json`** — 給 dashboard 篩選用，輕量、好維護。
```jsonc
{
  "_comment": "stock_id -> [tag,...]；多值、union-merge。優先序：watchlist 自訂 > 本表 > sub_industry > FinMind。",
  "2327": ["晶片電阻", "MLCC電容", "鉭質電容", "電感", "AI伺服器"],
  "2383": ["高速CCL", "AI伺服器", "CoWoS"],
  "8358": ["高階銅箔", "AI伺服器"],
  "1815": ["玻纖布", "AI伺服器"]
}
```

**檔 B：`tag_meta.json`** — 給研究／顯示用，存全球對標知識（就是本文 §2/§3 整理的內容）。
```jsonc
{
  "高速CCL": {
    "kind": "產品",
    "desc": "高速/低損耗銅箔基板（M6~M9 等級），AI 伺服器主板與交換器用",
    "tw_leaders": ["2383 台光電", "6274 台燿", "6213 聯茂"],
    "global": {
      "us": ["Isola", "Rogers"],
      "jp": ["Panasonic (MEGTRON)", "Resonac"],
      "kr": ["Doosan Electro-Materials"],
      "cn": ["生益科技 Shengyi", "Kingboard"]
    },
    "global_leader": "Panasonic / 台光電 / 生益（高速級三強並立）",
    "tw_is_global_leader": "並列前段",
    "note": "台光電 EMC 是 NVIDIA AI 板高速 CCL 主力之一；與 Panasonic、生益正面競爭；上游吃金居銅箔、富喬玻纖"
  }
}
```

> 為什麼分兩個檔：`tags.json` 你會常改（新股、重分類），希望 diff 乾淨；`tag_meta.json` 是慢變的「百科」，可單獨維護、單獨更新市占數字，兩者用 tag 字串當 join key。

## 3. 全球龍頭個股「主要業務 / 客戶 / 與台股關係」深入卡片（回答需求 4）

> 挑幾家最關鍵的對標標的，講清楚**主業、客戶、與台股是競爭/合作/上下游哪一種**。

### 🇰🇷 SK Hynix（HBM / DRAM）
- **主業**：DRAM、NAND、**HBM 全球龍頭**(2025 HBM 市占 ~53–57%)；2025 一度超越三星成全球最大記憶體廠。
- **客戶**：輝達(HBM 主力供應商)、AMD。
- **與台股關係**：**競爭**(對南亞科2408、華邦電2344 是降維打擊,但產品區隔——SK Hynix 走 HBM/主流 DRAM,台廠走利基);**上下游**(SK Hynix 的 HBM 要用台積電做 base die / CoWoS 封裝,所以對台積電是**客戶+合作**)。

### 🇯🇵 Murata 村田（MLCC / 被動元件）
- **主業**：**MLCC 全球第一**(~28–30%)、電感、RF 元件;垂直整合到鈦酸鋇粉體與鎳電極。
- **客戶**：Apple、車廠、AI 伺服器板。
- **與台股關係**：**競爭**(對國巨2327、華新科2492——但國巨/華新科多走中低階+利基,Murata 守高階車規/AI);AI 伺服器高容值 MLCC 需求讓兩邊都受惠。

### 🇯🇵 Ibiden（ABF 載板）
- **主業**：ABF 載板全球第二(僅次台灣欣興)、IC 載板;Intel/輝達 GPU 大載板主力。
- **客戶**：Intel、輝達、AMD。
- **與台股關係**：**競爭**(對欣興3037、南電8046、景碩3189)，AI GPU 大載板是雙方主戰場;Ibiden 在亞利桑那設廠搶 CHIPS 補貼。

### 🇺🇸 Coherent / Lumentum（光元件 / EML 雷射）
- **主業**：高速光收發模組、**EML/雷射晶粒**(1.6T 關鍵料)、矽光子元件。
- **客戶**：輝達、Google、微軟、AWS（透過模組廠）。
- **與台股關係**：對台股光通訊主要是**上游**(EML 雷射卡關料,台廠聯亞3081/全新2455 做 InP/GaAs 磊晶想切入這段,既是潛在競爭也可能是供料);對模組廠華星光是上游元件供應。

### 🇺🇸 Vertiv（液冷系統 / CDU）
- **主業**：資料中心電力與**液冷系統(CDU/機櫃級)全球龍頭**;併購 CoolTera/Strategic Thermal Labs 補冷板技術。
- **客戶**：所有大型 CSP / 資料中心。
- **與台股關係**：系統級是**競爭**(對台達電2308 的電力+液冷整櫃方案);零組件級是**上下游/合作**(向台廠採購散熱模組、cold plate——奇鋐3017/雙鴻3324/健策3653 可能是其供應商)。

### 🇺🇸 Amphenol / TE Connectivity（連接器）
- **主業**：連接器全球前二;高速背板連接器、AI 伺服器內部互連。
- **客戶**：所有伺服器 ODM、輝達。
- **與台股關係**：**競爭**(對貿聯3665、正崴2392——但台廠多做線束/cable assembly,與 Amphenol 部分重疊部分互補);AI 伺服器高速互連兩邊都吃。

### 🇯🇵 Shin-Etsu 信越（矽晶圓）
- **主業**：**矽晶圓全球第一**(與 SUMCO 合計過半)、光阻。

- **與台股關係**：對環球晶(中美晶5483 系)是**競爭**(全球前三);對台積電是**上游供應商**(晶圓原料)。

## 5. 維護建議 & 待辦清單

### 5.1 哪些數字「易變、要定期更新」（建議每季）

### 5.3 工程面待辦
1. 在 ETL (`gen_watchlist.py` / `build_data.py`) 加入 `tags.json` 的 union-merge 邏輯，與既有 sub_industry 串接。
2. Dashboard 篩選器支援多 tag **聯集 / 交集** 切換（例：`AI伺服器 ∩ 散熱模組`）。
3. 把 `tag_meta.json` 的 `global_leader` / `tw_is_global_leader` 做成 tooltip 或「全球對標」側欄。
4. 用 tag 做**供應鏈鏈路圖**（upstream/downstream 欄位已預留）：玻纖布→銅箔→CCL→PCB→載板→封測→伺服器。
5. 傳產股先只補 L2，不展開 tag（除非有跨界題材，如 1303 南亞有銅箔/電子材料,可補 `高階銅箔`）。

### 5.4 尚待你確認/補充的判斷點
- **tag 命名**：我用底線版(`NOR_Flash`、`伺服器管理IC_BMC`)避免特殊字元;若你 dashboard 對中文/斜線無礙,可改回 `光通訊/CPO` 風格。

- **傳產要不要也上 tag**：目前建議不上,但若你要做全市場輪動,可加 `內需 / 出口 / 高股息` 等財務型 tag。
