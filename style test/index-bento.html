指標說明 // 財報三表與五大指標

財報三大表互相連動：綜合損益表看「賺多少」、資產負債表看「家底與體質」、現金流量表看「真的收到多少現金」。獲利好不代表現金流好，三表一起看才能避免被單一數字誤導。

綜合損益表

一段期間（通常一季）公司「收入 − 成本費用 = 賺賠」的成績單。由上而下：營收 → 毛利 → 營業利益 → 稅前/稅後淨利 → EPS。能分辨賺的是本業還是業外。

資產負債表

某一時間點（季底）公司「有什麼（資產）、欠什麼（負債）、自己的（股東權益）」的快照。恆等式：資產 = 負債 + 股東權益。看財務結構是否穩健。

現金流量表

一段期間現金實際的進出，分三類：營業（本業收現，最重要）、投資（買設備/轉投資，擴張期常為負）、籌資（借還款、發股利）。本儀表板已將官方年度累計值還原為單季。

營收本業賣產品/服務的收入，獲利的源頭。台股每月 10 日前公布上月「月營收」，是最即時的領先指標。
獲利本儀表板以「營業利益」（本業賺錢能力）與「稅後淨利」為主軸，毛利率為品質輔助。EPS = 每股盈餘。
應收帳款已認列營收但客戶還沒付的錢。應收增速明顯快於營收 → 收款品質惡化或塞貨疑慮。
存貨尚未賣出的原料/在製品/成品。存貨↑但營收↓可能滯銷；存貨↑且營收↑多為備貨迎需求。
合約負債客戶預付但公司尚未交貨/認列的款項（在手訂單）。大增通常是未來營收的領先指標，AI 供應鏈特別值得關注。
總資產 / 總負債 / 股東權益公司規模與財務結構。股東權益 = 資產 − 負債，是真正屬於股東的淨值。
營業現金流本業實際收到的現金。若淨利為正但營業現金流長期為負，獲利品質需存疑（可能賺的是帳面數字）。
變動標記與排序

每檔顯示五大指標的 YoY（年增率）熱力色塊：上升暖色（玫紅）、下降冷色（青綠），色越深變動越大。等級：強烈 ±50%、顯著 30%、留意 15%。可依 YoY / QoQ / 絕對值 / 訊號嚴重度排序。基期過小者自動降權，避免假訊號。

訊號說明（交叉判讀）

單看一個指標漲跌容易誤判，「訊號」是結合多個指標的交叉規則，幫你快速判讀。表格最右欄會以彩色標籤呈現：

合約負債暴增合約負債 YoY ≥ 30%。客戶預付／在手訂單大增，通常是未來營收的領先指標，AI 供應鏈題材特別值得留意。
存貨↑營收↓存貨 YoY ≥ 15% 但營收 YoY ≤ 0。貨越積越多、銷售卻沒跟上 → 可能滯銷或需求轉弱（警示）。
備貨迎需求存貨與營收同步成長（皆 YoY ≥ 15%）。增加庫存是為了接單出貨，屬中性偏正。
應收>營收增速應收帳款 YoY 明顯高於營收 YoY（高出 10 個百分點以上）。收款速度跟不上認列營收 → 收款品質惡化或塞貨疑慮（警示）。

※ 沒有任何訊號時該欄顯示「—」，代表目前無明顯交叉警訊或亮點。
